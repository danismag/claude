## Сомнительные места
- kind-конфиг: формат kubeadm v1beta4 (extraArgs как список {name,value}, extraVolumes без изменений), apiVersion в патче; относительный hostPath `./audit-policy.yaml` от cwd. Сверено только с документацией kind (формат v1alpha4 и пути), v1beta4-форма — по знанию kubeadm.
- Тег образа узла `kindest/node:v1.36.1` и допущение, что он уже есть на хосте.
- Состав и порядок вывода `kind create cluster` (убраны эмодзи kind), вывод grep по манифесту (порядок флагов), `ls -l` лога.
- Вывод jq (шаги 6–7 лабы 1): `as:null`, код 403, имя пользователя kubernetes-admin; распределение уровней/стадий не приведено.
- Умолчания ротации аудита (maxage/maxbackup/maxsize) сознательно не названы: по документации не подтверждены, текст отсылает к --help. Ориентир 200 МБ = maxsize*(maxbackup+1) — арифметика.
- Умолчания webhook batch (10000/400/30 с/10/15), режимы blocking/blocking-strict — по документации audit.md.
- KubeletEnsureSecretPulledImages beta с 1.35, значение по умолчанию NeverVerifyPreloadedImages — по images.md; стадия гейта взята из задания.
- CEL: тернарный `has(...) ? list : []` и суммирование списков в переменной (лаба 2); возможна ошибка проверки типов.
- Admission-плагин AlwaysPullImages, подресурс pods/ephemeralcontainers — по знанию, не сверялось.
- Аннотация Audit-действия VAP в аудите — в тексте без точного ключа.
- Kyverno ClusterPolicy: поля (validationFailureAction, verifyImages.attestors.entries.keys.publicKeys) отличаются между версиями; policy-controller только упомянут.
- cosign v2.5.3 (существование версии), имя ассета cosign-linux-amd64 и cosign_checksums.txt, `COSIGN_PASSWORD=''` как пустой пароль, флаги --tlog-upload=false и --insecure-ignore-tlog, вывод verify (текст проверок), `no signatures found` после подмены тега, тег подписи `sha256-<hex>.sig` в registry:2.8.3.
- Дайджест из реестра через curl с несколькими Accept (два пути: busybox/1.37 и lab-06-4/orders-api; путь busybox в реестре стенда зависит от 02-1).
- Кросс-ссылки: 01-2 (static pod), 10-1 (kubeadm ClusterConfiguration), 09-2 (вебхуки), 08-2 (дайджест), 00-2 (jq) — номера частей по плану, § не цитируются.
