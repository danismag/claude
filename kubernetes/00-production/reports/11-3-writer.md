## Сомнительное
- Panic mode (§4): документация Envoy (panic_threshold) подтверждает только общее поведение: порог по умолчанию 50 %, 0 % отключает, при отключении и всех недоступных хостах 503 `no healthy upstream`. Что DRAINING-хосты (статус от Envoy Gateway для не-готовых эндпоинтов) считаются недоступными для паники, документация не говорит. Исходник Envoy Gateway сверен только по ветке main (route.go, getIREndpointsFromEndpointSlice: draining = Terminating || !Serving, иначе !Ready), версия 1.9.2 не сверялась. Текст оформлен как гипотеза с командами проверки (admin Envoy, порт 19000 — по памяти, не по документации). Замечание к 03-4 §2: там сказано, что «в кластер попадают только готовые поды»; наблюдение на стенде и исходник Envoy Gateway этому противоречат (не-готовые передаются с draining). Нужна правка 03-4 или ревью.
