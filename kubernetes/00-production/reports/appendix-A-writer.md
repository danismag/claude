# Отчёт писателя: приложение A «Шпаргалки»

Файл: kubernetes/appendix/A-cheatsheets.md (переписан поверх старой версии). Режим «только текст»: команды не запускались. Скрипт читаемости: 0 нарушений, средняя длина предложения 10,1 слова.

## Структура
Назначение, «Как пользоваться» (таблица страниц: страница, инструмент, карточка), 14 страниц A.1–A.14: kubectl, kind, crictl, journalctl для kubelet, etcdctl и etcdutl, kubeadm, helm 4 и helm-diff, kustomize, argocd, cosign, velero, tcpdump и netshoot, ingress2gateway, stern и k9s. На каждой: блок команд с комментарием к строке, «Частые ошибки» (3-4 пункта), «Подробно» со ссылкой на часть и раздел. В конце ссылки на приложения B-E.

## Источники
Команды взяты из карточек инструментов (00-2, 01-1, 10-1, 07-1, 07-2, 07-3, 08-1, 06-4, 04-3, 03-1, 03-5) и из частей 10-2, 10-3, 10-4, 11-1, 11-4, 00-1. Разделы в таблице страниц сверены по заголовкам.

## Сомнительные места
1. Короткие блоки (меньше 10 строк команд): velero 7, ingress2gateway 6, tcpdump 8, cosign 9, journalctl 9. Больше команд в курсе нет, флаги не выдумывались.
2. kuberc: курс сам даёт две формулировки: `KUBERC=off` (временно отключить файл) и `KUBECTL_KUBERC=false` (выключить механизм). В шпаргалке только `KUBERC=off`; `kubectl kuberc set` без флагов не приводится. Стоит сверить с документацией kubectl 1.36.
3. etcd: строка `defrag` дана без `--endpoints` (адрес уже в переменной E); в многочленном кластере нужен адрес каждого члена по очереди (10-2 §3). Строка `etcdutl snapshot restore` сокращена до `--data-dir`, `--bump-revision`, `--mark-compacted`; полный набор флагов (`--name`, `--initial-cluster`, ...) в 10-2, шаг 4 работы 2. `REV=$(... | jq ...)` запускается на хосте, как в 10-2.
4. cosign: дайджест `D` задан условной строкой с отсылкой к шагу 2 работы 3; в 06-4 он берётся curl-запросом заголовка манифеста.
5. velero: команды с `--namespace lab-04-3` по стенду 04-3; в 04-3 используется бинарник из `~/lab/k8s/04-3/bin`, в шпаргалке `velero` без пути.
6. kubeadm: строки `upgrade plan/apply/node` и `apt-mark` собраны из 10-3 §3; на стенде их выполняют иначе (подмена бинарника, 10-3 работа 3).
7. journalctl: запрос `kubectl get --raw .../proxy/logs/...` по умолчанию закрыт настройками kubelet (11-1 §3, 11-4 §3), в ошибках это сказано.
8. Старые разделы (таблица STATUS, числа для собеседования, kustomization-пример) убраны как выходящие за «страница на инструмент»; числа есть в модуле 12 и частях 11-2, 01-1.
