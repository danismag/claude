# Отчёт писателя: приложения D и E

Файлы: kubernetes/appendix/D-glossary.md, kubernetes/appendix/E-reading-list.md. Не закоммичено. Режим «только текст»: команды не запускались, ссылки не открывались.

## D. Глоссарий RU/EN
- Структура: назначение, «Как пользоваться» с четырьмя спорными парами, разделы по буквам (русские, затем латиница), связанные приложения. Формат записи: **термин** (english) — определение (NN-M). Если русский и английский совпадают (Deployment), скобок нет.
- Около 367 записей. Определения взяты из первого жирного определения в частях (grep по `\*\*[^*]+\*\* \(`), часть — по первому определению.
- Расхождения: ServiceAccount, 06-1; хуки Helm (07-1) и Argo CD (08-1) и волны (08-1); песочница пода (01-2) и песочница рантайма (06-2); выселение (eviction, 05-5) и вытеснение (preemption, 05-3).
- Сомнительные места: 05-5 называет node-pressure eviction «вытеснение по давлению», это противоречит разведению eviction/preemption. В глоссарии запись «Вытеснение по давлению» помечена как eviction; лучше поправить термин в 05-5 на «выселение по давлению». Часть для Pod/PV/PVC/Job/DaemonSet/ReplicaSet ставил по первому упоминанию, а не по полному разбору. Англ. эквиваленты некоторых записей (Watch, Pause, Heartbeat, Sidecar) вписаны мной, не жирным в тексте. Записи про имена Latin-section (kube-proxy и др.) определены по перечням в 01-1 и 01-2.
- Читаемость: списки длиннее 7 пунктов неизбежны в глоссарии по формату задания; прочие метрики в норме.

## E. Что читать
- Структура: назначение, «Как пользоваться», E.1 документация kubernetes.io (Concepts, Tasks, Reference, блог), E.2 KEP и CHANGELOG, E.3 книги, E.4 Hard Way, E.5 CKA/CKAD/CKS, E.6 документация инструментов, E.7 k8s.af, E.8 по модулям (три таблицы), E.9 смежные курсы.
- Книги: только название, авторы, издание; ссылок на магазины нет (в research-coverage они не открывались). Оглавления не пересказаны. Примеры к KiA и Patterns — GitHub, открывались при исследовании.
- Сомнительные места: URL kubernetes.io, kind, Helm, Kustomize, Argo CD, Gateway API, Envoy Gateway, cert-manager, CNPG, Velero, etcd, containerd, KEDA, Karpenter, k8s.af, sre.google написаны по памяти и корневым адресам, не проверялись. Страница «Helm 4 changes» дана без ссылки. Названия страниц в таблице E.8 (например «Tasks: Auditing») приблизительные. Авторы Production Kubernetes указаны как «и соавторы». Авторы Up and Running 3e (Burns, Beda, Hightower, Evenson) — по памяти.
